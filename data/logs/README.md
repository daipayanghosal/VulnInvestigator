# Log Events — Format Reference

This directory holds raw and simulated SIEM log event files consumed by the
VulnInvestigator pipeline.

---

## File Naming Convention

| Pattern | Description |
|---|---|
| `simulated_<technique_id>_<asset_id>.jsonl` | Events generated by `LogSimulator` |
| `raw_<date>.jsonl` | Real log exports (not committed to VCS) |

---

## JSONL Record Schema

Each line in a `.jsonl` file is a valid JSON object with the following fields:

| Field | Type | Description |
|---|---|---|
| `event_id` | `string` (UUID4) | Unique event identifier |
| `timestamp` | `string` (ISO 8601) | Event timestamp with timezone, e.g. `2026-01-15T14:32:01+00:00` |
| `asset_id` | `string` | Asset identifier matching `asset_inventory.json` |
| `source_ip` | `string` | Source IP address of the event originator |
| `event_type` | `string` | High-level event category (see table below) |
| `technique_id` | `string` | MITRE ATT&CK technique ID (e.g. `T1190`), or `""` for noise |
| `description` | `string` | Human-readable event description |
| `raw_log` | `string` | Simulated raw log line (key=value format) |
| `is_noise` | `boolean` | `true` if the event is unrelated background noise |

---

## Event Types

| `event_type` | ATT&CK Technique | Description |
|---|---|---|
| `web_exploit_attempt` | T1190 | HTTP exploit payload against a web application |
| `waf_alert` | T1190 | Web Application Firewall block event |
| `auth_success` | T1078 | Successful authentication (possibly anomalous) |
| `auth_failure_spike` | T1078 | Brute-force followed by successful login |
| `powershell_execution` | T1059 | Encoded/obfuscated PowerShell execution |
| `bash_reverse_shell` | T1059 | Outbound shell spawned from interpreter |
| `mass_file_rename` | T1486 | Ransomware-style bulk file encryption |
| `shadow_copy_deletion` | T1486 | VSS shadow copies deleted |
| `rdp_lateral_movement` | T1021 | RDP to a new internal host |
| `psexec_service` | T1021 | PsExec service installed on remote host |
| `scheduled_task` | *(noise)* | Routine system maintenance |
| `software_update` | *(noise)* | Software update check |
| `dns_query` | *(noise)* | Routine DNS resolution |

---

## Example Record

```json
{
  "event_id": "b4f1a2e3-d5c6-4789-a012-b3c4d5e6f789",
  "timestamp": "2026-01-15T14:32:01+00:00",
  "asset_id": "SRV-WEB-001",
  "source_ip": "203.0.113.99",
  "event_type": "web_exploit_attempt",
  "technique_id": "T1190",
  "description": "HTTP request with exploit payload targeting public-facing application",
  "raw_log": "src=203.0.113.99 dst=203.0.113.10 method=POST uri='/cgi-bin/admin.cgi' payload='../../../../etc/passwd' status=200",
  "is_noise": false
}
```
